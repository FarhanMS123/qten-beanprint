# Deep Research Skill Sources

This skill was synthesized by analyzing and merging strategies from 5 major open-source deep research repositories, plus 1 foundational source.

## Primary Source (1)
- **Antigravity Original Deep Research Skill**: The original global research skill self-made in the `.gemini/config/skills/` directory, providing the native Antigravity architecture, `gh` CLI mappings, and MCP (`server-sequentialthinking`, `server-memory`) integrations.

## GitHub Repositories & Prompt Files (5)

1. **dzhng/deep-research**
   - Files analyzed: `src/prompt.ts`
   - Contribution: Iterative depth/breadth searching, problem formulation, and strict query planning.

2. **assafelovic/gpt-researcher**
   - Files analyzed: `gpt_researcher/prompts.py`
   - Contribution: Comprehensive report synthesis, detailed sub-topic breakdown, and fact surveying.

3. **langchain-ai/open_deep_research**
   - Files analyzed: `src/open_deep_research/prompts.py`
   - Contribution: Action/Observation loop mapping, web surfing strategies, and state management.

4. **huggingface/smolagents**
   - Files analyzed: `examples/open_deep_research/run.py`
   - Contribution: Agentic looping, embedded prompting, and autonomous task execution.

5. **HKUDS/AutoAgent**
   - Files analyzed: `autoagent/agents/system_agent/websurfer_agent.py`
   - Contribution: Headless web surfing heuristics, evidence hunting, and SPA rendering strategies.
